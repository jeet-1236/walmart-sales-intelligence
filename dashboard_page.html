How the dataset was built

Four source files were merged into one table, and every experiment runs on that single integrated dataset.

  1. 1 Integration. The sales file was joined to the store file on Store, then to the features file on Store and Date. The result is — store-dept-week rows carrying sales, store attributes and local economic indicators side by side.
  2. 2 Preprocessing. Dates parsed to real timestamps, the holiday flag coerced to a boolean, markdown columns read as numbers with blanks treated as zero, and rows without a sales figure dropped.
  3. 3 Analysis. The eight experiments below, each written against the integrated table rather than the raw files.
  4. 4 Publication. Each experiment's results were exported as a table, and every figure on this dashboard is read from one of those tables. Open Sources on any number to see the file it came from and download it.

What to be careful about

Five things that would change a conclusion if ignored.

The markdown window

Markdown columns are blank for the first two years of the window and populated from November 2011 onward. In that later window every single record carries a non-zero markdown, so there is no zero-markdown control group anywhere in the data. Any "with promotion versus without" comparison on this dataset is comparing a recorded period with an unrecorded one, not a treated group with an untreated one.

The holiday flag

The flag marks the week ending after Christmas Day, which is a trough, and leaves the pre-Christmas peak unflagged. It also treats Super Bowl and Labor Day as equal to Thanksgiving. Used raw as a model feature it teaches the wrong calendar; replace it with named holidays and a week-of-year index.

The headroom figure is a ceiling

It assumes every store below the top-quartile benchmark could reach that benchmark. Catchment, local income and competition cap what any individual store can do, so treat it as the size of the prize worth investigating, not a target anyone should commit to.

Significance is not importance

At this sample size almost every test rejects its null hypothesis. The holiday difference has a p-value below any threshold and an effect size near 0.05, which is negligible. Read effect sizes and confidence intervals, not stars.

Correlation is not a promotion plan

The markdown depth curve rises steeply across records and almost flat within a store-dept. The cross-sectional version is mostly store size. Nothing here identifies a causal promotion effect; that needs a holdout group the data does not contain.

Two and a half years, one chain

The window opens in February 2010 and closes in October 2012, which gives only two complete Christmas peaks to learn seasonality from. Store identities are anonymous and there is no geography, so nothing here separates a regional effect from a store-specific one.
